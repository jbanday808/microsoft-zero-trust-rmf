# Zero Trust implementation

The [Azure DEV implementation](azure-dev/README.md) adds a practical build path to the repository's executive architecture, RMF, and STIG documentation.

Start with the [complete step-by-step guide](azure-dev/02-step-by-step-guide.md). The package contains deployable Azure Resource Manager templates, a private web application setup script, report-only access policy examples, network checks, and evidence templates.

The package is an educational design for a separate development environment. Deployment and control effectiveness must be verified in the user's tenant before they are described as completed.
